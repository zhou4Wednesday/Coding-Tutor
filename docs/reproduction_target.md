# Reproduction Target

Paper: Training Turn-by-Turn Verifiers for Dialogue Tutoring Agents(This paper is in ./docs/TRAVER.pdf)

Official repository:https://github.com/iwangjian/Coding-Tutor

Objective:
This project aims to use TRAVER as a baseline for the proposed tutoring benchmark, rather than strictly reproducing all results reported in the original paper.

The implementation includes three tasks:
Run the released TRAVER tutor successfully and verify that it can generate tutoring responses for coding problems.
Run the original DICT evaluation on a small subset to understand TRAVER's original evaluation workflow and obtain baseline results.

Current stage:
Analyze the official implementation and run a one-sample smoke test.
